# 월 990원 출시 실행표

작성: 2026-10-11. 사용자 결정: Pro 월 구독 가격은 990원으로 시작합니다.
기존 2026-10-10 보고서의 월 3,900원은 이전 가격 가설입니다. 가격 결정은 이 문서를 우선합니다.
Play Console 상품 생성·가격 적용·실제 결제는 아직 하지 않았습니다.

## 결정과 제안

- 확정: Pro 월 990원. 1인 개발자의 급여를 초기 현금 지출 예산에 넣지 않습니다.
- 제안: Free + Pro 두 등급으로 시작하고, 연간 상품과 AI 옵션 가격은 추후 결정합니다.
- 제안: 무료는 기본 시간·횟수·쿨다운, Pro는 앱 수 제한 해제·예약·집중 세션·주간 분석으로 구성합니다. 무료 앱 수와 최종 유료 범위는 아직 미확정입니다.
- 제안: AI·계정 동기화는 후속 단계로 둡니다. 아직 구현되지 않은 기능을 구매 혜택으로 표시하지 않습니다.
- 현재 오프라인 앱에는 서버·DB·AI 사용료가 발생하지 않습니다. 기존 월 63,000원은 유료 백엔드를 도입할 때의 예산 가정이며 현재 청구액이 아닙니다.
- 서버 기본료와 사용량 비용은 구분합니다. 스토어 수수료·환불·AI·트래픽은 고정비가 아닙니다. 본인 개발·문의 대응 시간은 일정에 반영합니다.
- 한국 Google Play 자동 갱신 구독의 현재 수수료는 15%입니다. 990원 전체가 수입으로 남지는 않으며, 세금·환불과 실제 정산 내역을 별도로 반영합니다. [수수료 안내](https://support.google.com/googleplay/android-developer/answer/112622?hl=en)

## 오늘 사용자가 할 일

소요 시간은 직접 작업 시간의 추정이며, 계정 심사·빌드·기기 문제 해결 대기는 별도입니다.

| 순서 | 할 일 | 준비 및 완료 기준 | 예상 |
|---|---|---|---|
| 1 | Google Play 계정 상태 확인 | 없음/개인/조직과, 기존 개인 계정이면 생성 시점 확인. 계정이 없으면 등록·본인 확인 시작 | 20~40분 |
| 2 | 출시 연락처 정하기 | 공개 개발자명, 문의 이메일, 앱 이름 후보 확인. 현재 앱 이름 ChronoLock, 패키지 com.chronolock | 10분 |
| 3 | 기존 APK 실기기 검사 | 아래 5개 검사를 각각 수행하고 성공/실패와 증상 기록 | 20~30분 |
| 4 | 비공개 테스트 참여자 확보 시작 | 신규 개인 계정이면 Android 사용자 최소 12명 참여 계획. 이탈에 대비한 여유 인원은 선택 | 15~30분 |

등록 시 US$25 일회 비용과 계정 유형에 따른 본인 확인이 필요합니다. 결제·본인 확인·정산 계좌 입력은 사용자가 Console에서 직접 진행합니다. [계정 등록](https://support.google.com/googleplay/android-developer/answer/6112435?hl=en)

2023-11-13 이후 생성한 개인 계정에는 최소 12명이 연속 14일 참여하는 비공개 테스트 요건이 적용됩니다. 충족 후 프로덕션 접근을 신청하며 승인까지 자동으로 완료되는 것은 아닙니다. 오늘은 참여자 확보와 테스트 배포 준비가 목표입니다. [테스트 요건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en-GB)

### 오늘의 기기 검사

기본 후보는 기존 갤럭시 탭 S9+ / Android 16 / YouTube입니다. 가능하면 Android 휴대전화에서도 반복합니다.
각 검사에서 다른 제한이 간섭하지 않게 테스트용 규칙과 기록을 초기화합니다. 초기화 전 보관할 개인 기록이 없는지 확인합니다.

| 검사 | 실행 | 기록할 결과 |
|---|---|---|
| 시간 | 일일 한도 60초 설정 후 사용 | 차단 시점, 표시된 사용량, 재진입 차단 여부 |
| 횟수 | 일일 3회 설정, 앱과 홈 왕복 | 1~3회 허용 및 4번째 차단 여부 |
| 쿨다운 | 30초 설정, 앱을 떠난 뒤 10초에 재진입 | 남은 시간 표시, 30초 이후 허용 여부 |
| 오프라인 | 비행기 모드에서 위 검사 반복 | 각 제한과 기록 저장 여부 |
| 재부팅 | 규칙·사용량 기록 후 기기 재부팅 | 규칙·사용량 유지와 감지 재개 여부 |

## 개발 작업 순서

아래는 남은 작업이며 이 문서 작성으로 구현 완료된 항목이 아닙니다.

1. **빌드·출시 기반:** Android SDK 36 및 호환 빌드 도구 대응, APK 빌드·Lint·기존 테스트 실행. 현재 compileSdk/targetSdk는 35입니다. 신규 제출에는 API 36 이상이 요구됩니다. [타깃 API 요건](https://support.google.com/googleplay/android-developer/answer/11926878?hl=en)
2. **차단 신뢰성:** 오늘 기기 검사에서 발견한 문제 수정. 잠금·날짜 경계·접근성 재연결·기록 복구도 검증합니다.
3. **유료 기능:** 신뢰성 검증 후 1회 한도 → 요일/시간 예약 → 집중 세션 → 주간 분석 순서로 구현합니다. 최초 Pro에 넣을 기능을 확정하고 완성된 기능만 표시합니다.
4. **결제:** Google Play Billing, 월 990원 기본 요금제, 구매 검증 서버와 구독 상태 반영, 복원·해지·환불·만료·오프라인 처리. Console에서 한국 표시 가격을 확인하고 실제 결제 전에 라이선스 테스트를 수행합니다.
5. **출시 자료:** 개인정보처리방침, 접근성 사용 설명·동의 및 신고, Data safety, 스토어 소개·아이콘·스크린샷, 릴리스 서명·AAB 준비. 실제 구현과 수집 항목을 대조합니다.
6. **배포:** 내부 테스트 → 필요한 비공개 테스트 → 피드백 수정 → 프로덕션 접근 신청 및 단계 출시.

구독은 지속적인 가치를 제공해야 하므로 실제 제공 기능·가격·자동 갱신·취소 방법을 명확히 안내합니다. [구독 정책](https://support.google.com/googleplay/android-developer/answer/9900533?hl=en)

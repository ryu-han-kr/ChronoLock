# ChronoLock 다음 기능 제안

작성: 2026-10-15. 현재 코드와 사용자 피드백을 기준으로 한 제품 제안이며, 아래 신규 기능을 구현했다는 의미는 아닙니다.

현재 앱별 하루 한도·실행 횟수·1회 한도·재실행 대기·단일 예약, 25/50/90분 집중,
레시피, 7일 기록, 권한 상태 안내가 있습니다. 이번 작업은 시/분/초 입력, 예약 요일 기본값,
5개 테마와 저장 기능을 개선합니다.

## 추천 순서

| 순서 | 기능 | 사용자가 얻게 되는 점 | 현재 기능에서 추가할 내용 | 규모 |
|---|---|---|---|---|
| 1 | 첫 설정 안내와 감지 상태 점검 | 설정했는데 차단이 안 되는 혼란 감소 | 권한 설명 → 권한 켜기 → 감지 연결 확인 → 첫 앱 설정까지 진행 상태를 표시. 감지 중단과 복구 시점도 안내 | 중 |
| 2 | 남은 사용시간·다시 사용 가능한 시각 | 제한 결과를 미리 이해 | 앱 카드에 ‘오늘 12분 남음’, 차단 화면에 해제 예상 시각과 적용 중인 모든 규칙 표시. 복합 규칙이면 해제 시각을 확정할 수 없는 경우도 설명 | 중 |
| 3 | 시간 입력 방식 통일 | 초 단위 환산 없이 설정 | 1회 사용시간과 재실행 대기도 시/분/초로 입력. 자주 쓰는 5/10/30분 프리셋 추가 | 소 |
| 4 | 평일·주말 및 여러 예약 구간 | 공부·업무·취침 시간 구분 | 현재 앱별 예약 한 구간을 여러 구간으로 확장. 평일/주말 선택 버튼은 사용자가 누를 때만 선택. 겹치는 구간·자정 넘김 검사 | 대 |
| 5 | 앱 묶음과 집중 프로필 | 여러 앱을 한 번에 관리 | ‘공부’, ‘업무’, ‘취침’별 대상 앱과 제한을 저장. 그룹 총 사용시간 공유는 후속 단계로 분리 | 대 |
| 6 | 종료 시각이 있는 일시 중지 | 잠깐 해제 후 다시 켜는 것을 잊지 않음 | 현재 수동 켜기/끄기에 ‘10분 쉬기’, ‘오늘만 해제’를 추가. 어떤 규칙을 일시 중지하는지 명시하고 재시작 후에도 복구 | 중 |
| 7 | 주간 비교 리포트 | 설정이 자신에게 맞는지 판단 | 현재 7일 합계에 지난주 대비 변화, 앱별 분포, 기록 누락 표시 추가. ‘절약한 시간’은 근거 없이 계산하지 않음 | 중 |
| 8 | 로컬 백업·복원 | 기기 변경·재설치 시 규칙 보존 | 사용자가 선택한 파일로 규칙을 내보내고 가져오기. 버전·중복 앱·설치되지 않은 앱을 확인하며 덮어쓰기 전 미리보기 제공 | 중 |
| 9 | 홈 화면 위젯·빠른 설정 타일 | 앱을 열지 않고 집중 시작 | 집중 시작/종료와 남은 시간 표시. 잠금 화면 공개 정보와 오작동 방지 동작을 검토 | 중 |
| 10 | 집중 시간 직접 지정 | 자신의 작업 길이에 맞춤 | 현재 25/50/90분 외에 직접 입력, 자주 쓰는 시간 저장. 시작 전 대상 앱 확인 동작 유지 | 소 |

규모는 상대적인 구현·검증 범위이며 일정 추정은 아닙니다.

## 다음 한 묶음으로 권하는 범위

우선 **감지 상태 안내 + 남은 시간 표시 + 시간 입력 통일**을 권합니다.
사용자가 설정 결과를 이해하고 믿고 쓸 수 있게 하는 것이 먼저입니다.
그다음 여러 예약과 앱 묶음을 추가하면 반복 설정을 줄일 수 있습니다.

로그인·클라우드 동기화·AI 코칭·친구 순위는 뒤로 미루는 편이 좋습니다.
서버 운영, 데이터 동의, 비용 관리가 추가되므로 현재의 기기 내 집중 도구 경험을 먼저 검증합니다.
구독은 이미 정한 월 990원 계획을 유지하되, 위 기능을 모두 유료로 묶는 결정은 사용 피드백 이후에 합니다.

## 출시 전에 기능과 함께 확인할 것

- 권한 해제, 서비스 재연결, 기기 재부팅 후 제한·기록의 실제 동작.
- 작은 화면·큰 글씨·태블릿에서 입력창과 테마 대비.
- 예약 요일 미선택, 자정 넘김, 여러 제한 동시 도달 시 설명의 정확성.
- 테마·규칙의 저장과 앱 재실행 후 복원.

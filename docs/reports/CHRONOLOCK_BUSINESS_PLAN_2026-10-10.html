02. 추천 기능 10개 — 일반 기능 1~5

다음은 구현 제안이며 아직 적용되지 않았습니다. P1은 초기 차단 신뢰성 검증 후 우선, P2는 사용자 반응을 확인한 뒤 진행합니다. 이미 명세에 있는 범위를 구체화했습니다.

번호 / 우선순위 기능 사용 예시 구현 범위와 완료 기준
1 · P1 1회 사용시간 제한 YouTube를 열 때마다 최대 10분 기존 도메인 판정에 저장·편집 UI 연결. 시간 도달·앱 전환·재진입과 쿨다운 조합 테스트
2 · P1 요일·시간대 예약 평일 23시~다음 날 7시 제한 밤샘 구간, 요일 귀속, 시간대 변경, 일광절약시간을 일관되게 처리
3 · P1 집중 세션 25·50·90분 동안 선택 앱 제한 시작·완료·취소와 남은 시간 표시. 프로세스 재시작 후 종료 시각 유지
4 · P1 주간 행동 대시보드 사용량은 낮지만 재실행이 잦은 앱 발견 사용시간·실행 횟수·차단·야간 비율 표시. 차트 합계와 원시 기록 집계 일치
5 · P2 규칙 기반 추천 5분 이내 재실행 비율이 높으면 쿨다운 제안 명세 15장의 결정적 추천 엔진. 근거·적용·거절·수정 제공. LLM 비용 없이 동작

유료화 연결

일일 시간·횟수·쿨다운의 기본 사용 경험은 무료로 유지합니다. 장기 분석과 다양한 일정, 집중 세션 기록 등 반복해서 이용할 가치를 Pro에 묶습니다. 단순히 사용을 막는 기능만으로 구독 가치를 설명하기보다 “계획 → 사용 → 회고 → 개선”을 완성합니다.

개발 순서

1 → 2 → 3 → 4 → 5를 권장합니다. UI만 추가하지 않고 규칙 저장, 재시작 복원, 오프라인 동작과 테스트를 묶어서 완성합니다. 실제 사용자 요청이 적은 기능은 순서를 조정합니다. 일정은 SDK 업그레이드와 기기 문제 해결 후 산정하며, 아래 로드맵은 순서 제안입니다.

04. 광고 없는 정액제 제안

가격은 한국 사용자 대상 검증용 가설입니다. 아직 결제 상품을 생성하거나 청구하지 않습니다.

상품 가격안 제공 가치
Free 0원 선택 앱 최대 3개에 기본 시간·횟수·쿨다운, 오늘 기록, 로컬 저장
Pro 월간 월 3,900원 앱 수 제한 해제, 일정·집중 세션, 장기 분석, 추천, 동기화가 완성되면 포함
Pro 연간 연 39,000원 월 환산 3,250원. 월 결제 12회 대비 약 16.7% 할인
AI 옵션 Pro에 월 2,900원 추가 주간 회고 월 4회 + 대화형 제안 월 8회. 합계 월 12회, 총 월 6,800원

초기에는 Free + Pro 두 등급만 출시하고 AI 옵션은 나중에 열어도 됩니다. 기존 테스트 사용자의 저장된 규칙을 과금 도입과 동시에 삭제하지 않습니다. 유료 기간 종료 시 어떤 규칙과 기능이 어떻게 전환되는지 미리 알리고, 권한·개인정보 설정·기록 삭제는 항상 접근 가능하게 유지합니다.

구독의 명분과 결제 경험

반복 사용 가능한 분석·추천·동기화 등 지속적인 가치를 실제 제공한 뒤 구독을 판매합니다. 서비스가 지속적 가치를 제공해야 한다는 Google Play 구독 정책을 기준으로 가격, 결제 주기, 자동 갱신, 취소 경로, 체험 후 청구 시점을 명확히 표시합니다.

초기 결제는 Google Play Billing을 기준으로 설계합니다. 서버에서 구매 검증, 구독 상태 변화, 복원·취소·유예·보류·환불을 처리하고, 기기에는 검증된 권한을 제한된 기간 캐시합니다. 결제 서버 오류가 이미 설정된 로컬 차단을 갑자기 해제하지 않도록 전환 정책을 테스트합니다.

광고 운영안

첫 출시 외부 광고 0개를 권장합니다. 무료 사용자는 설정·분석 화면의 절제된 Pro 안내로 전환합니다. 차단 화면에 전면 광고, 광고를 보면 제한 해제, 앱 목록·행동 기록을 이용한 광고 타기팅은 도입하지 않습니다. 광고 수익은 아래 매출 계산에 포함하지 않습니다.

가격 검증

실제 베타 사용자를 대상으로 유료 가치와 이탈 사유를 확인합니다. 3,900원과 4,900원을 별도 모집 집단에서 비교하는 소규모 실험을 제안합니다. 전환율 3%는 계산 가정이며 시장 실적이 아닙니다.

# ChronoLock
## 기능 · 출시 · 구독 · 운영비 제안서

**2026.10.10 · 의사결정용 초안 · 한국 Android 시장 우선**

사용자가 자신의 앱 사용을 시간·횟수·재실행 간격으로 조절하는 서비스.
핵심 차단은 기기에서 실행하고, 광고 없이 구독으로 지속 가능한 운영을 목표로 합니다.

### 이번 제안의 핵심

| 결정 | 제안 |
|---|---|
| 첫 출시 | Google Play의 Android 앱. Apple App Store는 iOS 개발 이후 |
| 광고 | 첫 정식 버전은 외부 광고 SDK 없이 운영 |
| 요금 | Free / Pro 월 3,900원 또는 연 39,000원 / AI 선택 추가 월 2,900원 |
| 기능 확장 | 기존 명세 안에서 7개 일반 기능 + 선택형 AI 기능 3개 |
| 초기 운영 예산 | 유료 백엔드 도입 시 월 **$45 ≈ 63,000원**, 일평균 **$1.50 ≈ 2,100원** |
| 비용 알림 | 매일 오전 9시 KST에 Discord 요약 + 이메일 상세 보고서 제안 |

**숫자 읽는 법:** 구독 가격·전환율·운영 예산은 제안과 계산 가정입니다. 실제 매출이나
현재 발생 중인 청구액이 아닙니다. 환산은 비교용 **1 USD = 1,400원**, 월 **30일**을 사용합니다.
해외 서비스 세금·환전 수수료·인건비·마케팅비는 별도입니다. 공식 단가의 확인일은 2026-10-10입니다.

### 확인된 현재 상태

도메인 테스트 32개, Android 35 저장소 테스트 4개, APK 빌드와 Lint가 통과했습니다.
갤럭시 탭 S9+ **SM-X810 / Android 16(API 36)**에 설치했고, 사용자가 “잘 된다”고 확인했습니다.
다만 A/B/C의 개별 수치, 차단 지연, 오프라인·재부팅 결과는 아직 각각 기록되지 않았습니다.
이 피드백만으로 모든 실기기 수용 조건을 통과한 것으로 처리하지 않습니다.

**이번 산출물은 기획·비용·알림 설계입니다.** 구독, AI, 서버, 자동 발송은 아직 활성화하지 않았습니다.
원본 Markdown, 크롬용 HTML, PDF를 함께 제공합니다. HTML의 계산기에서 가정을 바꿔 볼 수 있습니다.

### 아직 제품 기능으로 제공하지 않는 것

세션별 한도·시간대 스케줄·집중 세션은 **도메인 판정만** 존재하며 저장·설정 화면은 없습니다.
주간 분석, 개인화 추천, 계정, 동기화, 결제, AI, 서버와 iOS는 미구현입니다.
현재 화면은 오늘 / 앱 제한 / 설정의 3개 탭입니다. 무료·유료 등급 제한도 아직 없습니다.

### 정식 출시 전에 해결할 품질 항목

- 서비스 중단 중 실행 횟수 복구, 잠금·앱 전환·날짜 경계·재부팅의 정확성 확인.
- 태블릿의 DeX·분할 화면·PiP 처리 정책 확정 및 실제 검증. 현재 지원을 약속하지 않습니다.
- 접근성 서비스 중단 안내, 차단 화면에서 시스템 설정과 긴급 연락 접근 확인.
- 백업 제외 설정·문자열 리소스·오래된 라이브러리 등 Lint 경고 19개 검토.
- 태블릿과 휴대전화, 큰 글씨, 가로 화면, TalkBack, 배터리 절약 모드 점검.

**측정 기준:** 60초 도달 후 표시 지연, 중복 실행 횟수, 재부팅 전후 카운터를 각각 기록합니다.
“절대 우회 불가”, “지연 0초” 같은 제품 약속은 하지 않습니다.

## 02. 추천 기능 10개 — 일반 기능 1~5

다음은 구현 제안이며 아직 적용되지 않았습니다. P1은 초기 차단 신뢰성 검증 후 우선,
P2는 사용자 반응을 확인한 뒤 진행합니다. 이미 명세에 있는 범위를 구체화했습니다.

| 번호 / 우선순위 | 기능 | 사용 예시 | 구현 범위와 완료 기준 |
|---|---|---|---|
| 1 · P1 | **1회 사용시간 제한** | YouTube를 열 때마다 최대 10분 | 기존 도메인 판정에 저장·편집 UI 연결. 시간 도달·앱 전환·재진입과 쿨다운 조합 테스트 |
| 2 · P1 | **요일·시간대 예약** | 평일 23시~다음 날 7시 제한 | 밤샘 구간, 요일 귀속, 시간대 변경, 일광절약시간을 일관되게 처리 |
| 3 · P1 | **집중 세션** | 25·50·90분 동안 선택 앱 제한 | 시작·완료·취소와 남은 시간 표시. 프로세스 재시작 후 종료 시각 유지 |
| 4 · P1 | **주간 행동 대시보드** | 사용량은 낮지만 재실행이 잦은 앱 발견 | 사용시간·실행 횟수·차단·야간 비율 표시. 차트 합계와 원시 기록 집계 일치 |
| 5 · P2 | **규칙 기반 추천** | 5분 이내 재실행 비율이 높으면 쿨다운 제안 | 명세 15장의 결정적 추천 엔진. 근거·적용·거절·수정 제공. LLM 비용 없이 동작 |

### 유료화 연결

일일 시간·횟수·쿨다운의 기본 사용 경험은 무료로 유지합니다. 장기 분석과 다양한 일정,
집중 세션 기록 등 반복해서 이용할 가치를 Pro에 묶습니다. 단순히 사용을 막는 기능만으로
구독 가치를 설명하기보다 “계획 → 사용 → 회고 → 개선”을 완성합니다.

### 개발 순서

**1 → 2 → 3 → 4 → 5**를 권장합니다. UI만 추가하지 않고 규칙 저장, 재시작 복원,
오프라인 동작과 테스트를 묶어서 완성합니다. 실제 사용자 요청이 적은 기능은 순서를 조정합니다.
일정은 SDK 업그레이드와 기기 문제 해결 후 산정하며, 아래 로드맵은 순서 제안입니다.

### AI가 있어도 바뀌지 않는 원칙

차단 여부는 순수 Kotlin RuleEngine만 결정합니다. AI는 설정을 직접 바꾸거나 접근성 기능을
실행하지 않습니다. Google Play는 사람이 정한 결정적 자동화와 자율적 계획·실행을 구분합니다.
[접근성 정책](https://support.google.com/googleplay/android-developer/answer/10964491?hl=en)

원시 앱 사용 이벤트는 기기에 두고 사용자가 동의한 집계만 전달합니다. AI를 끄거나 통신이
실패해도 로컬 제한은 유지합니다. 텍스트 입력과 생성 결과는 앱에서 신뢰하지 않고 JSON 구조,
앱 식별자, 설정 범위와 허용 값으로 검증합니다. 앱·태블릿에 서비스 API 키를 넣지 않습니다.

**도입 조건:** 추천 5번으로 효과를 먼저 확인 → 한국어 설명 품질·잘못된 수치·잘못된 규칙을
시험 → AI 추가 요금에 대한 수요 확인. 무제한 상담, 음성·이미지 생성은 초기 범위에서 제외합니다.

## 04. 광고 없는 정액제 제안

가격은 한국 사용자 대상 **검증용 가설**입니다. 아직 결제 상품을 생성하거나 청구하지 않습니다.

| 상품 | 가격안 | 제공 가치 |
|---|---|---|
| **Free** | 0원 | 선택 앱 최대 3개에 기본 시간·횟수·쿨다운, 오늘 기록, 로컬 저장 |
| **Pro 월간** | 월 3,900원 | 앱 수 제한 해제, 일정·집중 세션, 장기 분석, 추천, 동기화가 완성되면 포함 |
| **Pro 연간** | 연 39,000원 | 월 환산 3,250원. 월 결제 12회 대비 약 16.7% 할인 |
| **AI 옵션** | Pro에 월 2,900원 추가 | 주간 회고 월 4회 + 대화형 제안 월 8회. 합계 월 12회, 총 월 6,800원 |

초기에는 Free + Pro 두 등급만 출시하고 AI 옵션은 나중에 열어도 됩니다. 기존 테스트 사용자의
저장된 규칙을 과금 도입과 동시에 삭제하지 않습니다. 유료 기간 종료 시 어떤 규칙과 기능이
어떻게 전환되는지 미리 알리고, 권한·개인정보 설정·기록 삭제는 항상 접근 가능하게 유지합니다.

### 구독의 명분과 결제 경험

반복 사용 가능한 분석·추천·동기화 등 지속적인 가치를 실제 제공한 뒤 구독을 판매합니다.
서비스가 지속적 가치를 제공해야 한다는 [Google Play 구독 정책](https://support.google.com/googleplay/android-developer/answer/9900533?hl=en)을 기준으로
가격, 결제 주기, 자동 갱신, 취소 경로, 체험 후 청구 시점을 명확히 표시합니다.

초기 결제는 Google Play Billing을 기준으로 설계합니다. 서버에서 구매 검증, 구독 상태 변화,
복원·취소·유예·보류·환불을 처리하고, 기기에는 검증된 권한을 제한된 기간 캐시합니다.
결제 서버 오류가 이미 설정된 로컬 차단을 갑자기 해제하지 않도록 전환 정책을 테스트합니다.

### 광고 운영안

첫 출시 **외부 광고 0개**를 권장합니다. 무료 사용자는 설정·분석 화면의 절제된 Pro 안내로
전환합니다. 차단 화면에 전면 광고, 광고를 보면 제한 해제, 앱 목록·행동 기록을 이용한
광고 타기팅은 도입하지 않습니다. 광고 수익은 아래 매출 계산에 포함하지 않습니다.

### 가격 검증

실제 베타 사용자를 대상으로 유료 가치와 이탈 사유를 확인합니다. 3,900원과 4,900원을
별도 모집 집단에서 비교하는 소규모 실험을 제안합니다. 전환율 3%는 계산 가정이며 시장 실적이 아닙니다.

| 2. 계정 | 개인/조직 선택, 신원 확인, 개발자·정산 정보 | Console 계정 상태 정상 |

| 5. 테스트 배포 | 내부 테스트 → 실제 대상 사용자의 비공개 테스트 | 피드백과 수정 내역, 시나리오별 결과 |

현재 `targetSdk=35`입니다. 확인한 정책은 **2026-08-31부터 신규 앱·업데이트에 API 36 이상**을
요구합니다. 실제 심사 제출 시 Console 적용 조건을 다시 확인해야 합니다.
[타깃 API 정책](https://support.google.com/googleplay/android-developer/answer/11926878?hl=en)

신규 개인 계정(2023-11-13 이후 생성)은 최소 **12명이 연속 14일 참여한 비공개 테스트** 후
프로덕션 접근을 신청하는 요건이 있습니다. 계정 유형·생성 시점에 따라 적용 여부를 확인합니다.
[테스트 요건](https://support.google.com/googleplay/android-developer/answer/14151465?hl=en)

ChronoLock은 장애 지원 도구가 아닌 자기조절 앱이므로 그 목적에 맞는 접근성 신고와 동의가
필요합니다. 심사 승인을 미리 보장하지 않습니다. 계정 기능을 도입하면 탈퇴·서버 데이터 삭제와
AI 전송 동의도 실제로 구현합니다. [접근성 신고](https://support.google.com/googleplay/android-developer/answer/10964491?hl=en)

## 07. 선택형 AI 비용과 예산 통제

비용 예시 모델은 **GPT-5.4 Mini**입니다. 최종 채택은 한국어 품질·잘못된 규칙 제안·지연 평가 후
결정합니다. 공식 텍스트 표준 단가는 100만 토큰당 입력 **$0.75**, 출력 **$4.50**입니다.
캐시 할인·Batch 할인·유료 도구 호출은 이 계산에 넣지 않았습니다.
[공식 모델 단가](https://developers.openai.com/api/docs/models/gpt-5.4-mini)

### 호출량을 정한 비용 예시

| 항목 | 가정 및 계산 |
|---|---|
| 1회 입력 | 3,000토큰: 집계 지표·규칙·짧은 대화 이력 |
| 1회 청구 출력 | 800토큰 가정: 추론 토큰을 사용할 경우 그 비용까지 출력 예산에 포함 |
| 1회 모델 비용 | 3,000 × 0.75 / 1,000,000 + 800 × 4.50 / 1,000,000 = **$0.00585** |
| 1인 월 사용 | 12회 → **$0.0702** |
| 20% 재시도·변동 여유 | **$0.08424 ≈ 118원 / AI 이용자·월** |
| AI 이용자 100명 | **$8.424 ≈ 11,794원/월**, 일평균 약 393원 |
| AI 이용자 1,000명 | **$84.24 ≈ 117,936원/월**, 일평균 약 3,931원 |

이 값은 정해 둔 토큰·호출량 안의 계산 예시입니다. 사용자가 늘어날 때 서버·DB도 추가될 수 있으며,
긴 프롬프트·큰 출력·추론·재시도·지역 처리 할증 등으로 실제 금액이 달라집니다.
실제 응답의 usage 값과 공급자 비용을 대조합니다. AI 옵션 가격은 API 비용뿐 아니라
품질 검증·지원·개인정보 관리·운영비를 포함한 제품 가격입니다.

### 비용을 제어하는 제품 설계

- 집계 데이터가 바뀌지 않으면 이미 만든 회고를 재사용합니다.
- 서버에서 사용자별 월 12회 한도, 요청당 입력·출력 한도, 제한된 재시도와 호출 예약을 적용합니다.
- 제안이 검증되지 않으면 규칙을 저장하지 않고 기존 결정적 추천으로 안내합니다.
- 월 AI 예산의 50/80/100% 도달을 알립니다. 동시 요청의 예상 비용도 예약해 초과 폭을 제한합니다.
- 운영자가 지정한 한도 도달 시 새 AI 작업을 중지하되 기존 앱 차단은 계속 동작합니다.
- 서비스 공급자의 알림만을 하드 한도로 간주하지 않고 앱 서버에서 통제합니다.

## 08. 매출·손익 시뮬레이션

한국의 자동 갱신 구독을 Google Play Billing으로 판매하는 경우를 기준으로 수수료 **15%**를
계산 가정으로 사용합니다. 지역·프로그램·결제 방식에 따라 달라질 수 있습니다.
[Google Play 수수료](https://support.google.com/googleplay/android-developer/answer/112622?hl=en)

아래는 소비자가 3,900원에 부가세 10%가 포함됐다고 **가정한 기획 계산**입니다.
`1인 월 정산 추정 = 3,900 ÷ 1.10 × (1 − 0.15) = 약 3,014원`.
실제 세금 징수·수수료 과표·정산은 판매 국가와 Console 명세를 확인해야 합니다.

| 월 활성 사용자(MAU) | 유료 전환 가정 | Pro 월간 이용자 | 소비자 결제 총액 | 정산 추정 | 인프라 예산 | 운영 잔액 |
|---:|---:|---:|---:|---:|---:|---:|
| 100 | 3% | 3명 | 11,700원 | 9,041원 | 63,000원 | **−53,959원** |
| 1,000 | 3% | 30명 | 117,000원 | 90,409원 | 63,000원 | **27,409원** |
| 10,000 | 3% | 300명 | 1,170,000원 | 904,091원 | 210,000원 | **694,091원** |

10,000 MAU의 월 $150는 성장 예산 가정이며 성능 보장이 아닙니다. 실제 동시접속·API·집계 부하로
서버 증설을 결정합니다. 운영 잔액은 **인건비·마케팅·환불·AI·기타 세금을 제외한 값**이므로 순이익이 아닙니다.
이 표에는 연간 상품과 AI 추가 요금 매출을 넣지 않았습니다.

### 손익분기와 연간 상품

- 월 고정 예산 63,000원만 회수하려면 Pro 월간 이용자 **21명**이 필요합니다.
- 월 1,000 MAU 기준으로는 약 **2.1%** 전환에 해당합니다. 인건비를 넣으면 더 높아집니다.
- 연 39,000원은 월 인식 매출 3,250원입니다. 같은 세금·수수료 가정의 월 정산 환산은 약 2,511원,
  같은 고정비 회수에는 **26명**이 필요합니다. 연 결제 현금 유입과 월 매출 인식을 분리합니다.
- AI 옵션 2,900원의 정산 가정 약 2,241원에서 모델 예산 118원을 빼면 약 2,123원입니다.
  이는 AI 관련 추가 지원·인프라·환불·인건비를 차감하기 전 기여액입니다.

### 실제 사용자 확보안

집중·공부·업무 중 반복 실행을 줄이고 싶은 성인 사용자를 먼저 모집합니다. 20~30명 베타에서
권한 설정 완료율, 7일·30일 유지율, 제한의 오작동, 사용자가 체감한 유용성, 유료 의향을 확인합니다.
허위 리뷰나 긍정 평가 대가 지급 없이 자발적 피드백을 받고, 허락받은 사례만 소개합니다.

## 10. 보고서 예시와 안정적인 발송

아래 숫자는 화면 구성용 **가상 예시**이며 실제 청구 데이터가 아닙니다.

```text
[ChronoLock 비용 보고 · 예시] 2026-10-09 / 09:00 KST 발송
기준: 운영일 KST / AWS·AI 비용 버킷 UTC 별도 표시

전일 운영비 추정: $1.64 (약 2,296원)
  AWS 잠정 $0.42 / DB·고정비 안분 $1.08 / AI 추정 $0.14
이번 달 누적 추정: $14.50
월말 예상: $50.85 / 월 예산: $60 / 예상 잔액: $9.15
예산 예상 사용률: 84.8% → 주의

수집 상태: AWS 잠정 / Supabase 추정 / AI 추정
공식 인보이스: 오늘 신규 발행 없음
필요 조치: AI 요청 증가 원인 확인
```

### 채널별 전달

Discord는 운영자 전용 채널의 Incoming Webhook으로 짧은 요약·경고·상세 보고서 링크를 보냅니다.
개별 사용자 앱 목록·사용 기록은 포함하지 않습니다. 웹훅 주소는 비밀 값으로 보관하고,
전송 시 불필요한 사용자 멘션을 막습니다. [Discord Webhook](https://docs.discord.com/developers/resources/webhook)

이메일은 HTML 본문 + CSV 원장 또는 일일 PDF로 자세히 보냅니다. 공식 인보이스는 가능하면
운영자의 비공개 이메일로 전달하고 Discord에는 발행 사실만 알립니다. SES는 발신 도메인 인증과
수신 가능 여부를 확인합니다. 샌드박스에서는 검증된 수신자 제한을 고려합니다.
[SES 발송 준비](https://docs.aws.amazon.com/ses/latest/dg/request-production-access.html)

### 운영 방식 제안

이미 운영할 Lightsail 서버에서 일별 작업을 실행하고 DB에 `(날짜, 채널, 보고서 버전)` 발송 이력을
저장합니다. 중복 발송 방지, 재시작 후 누락일 보충, 채널별 성공·실패와 제한된 재시도를 구현합니다.
Discord의 429 응답과 Retry-After를 존중합니다. 이메일 한쪽 실패가 다른 채널 발송을 막지 않게 합니다.

수집 실패는 **0원으로 기록하지 않고 미수집**으로 표시합니다. 최근 7일 잠정 비용을 재수집해
보정하고, 월말에는 인보이스·크레딧·세금과 대조합니다. 비용 급증 알림은 일일 보고와 별도로 처리합니다.
공식 청구서의 자동 취득이 지원되지 않는 공급자는 billing 이메일 수신·수동 첨부 방식부터 시작합니다.

**알림 기준 제안:** 월 예산 50/80/100%, 일비용 최근 7일 평균의 2배이면서 $5 이상,
수집 48시간 이상 지연. 전체 예산은 알림 기준이고, 자동 중지는 우선 AI 같은 선택 기능에만 적용합니다.

  감시 루프가 예외 1회로 영구 중단되던 문제(연속 5회 실패 때만 중단). 잠금 해제 후 사용 통계가 비면 잠금 전 앱 재관찰.
  화면 꺼짐 동안 매초 DB 쓰기 중단. 안전 패키지 조회 1분 캐시. 하루 1회 경고를 재시작 후에도 유지. HistoryJobService 실패 로그.
- UI: 마스코트 회전 대사 4개 번역 추가(+LocalizationTest). 추천 앱 잠금에서 레시피 값이 빈 폼으로 열리던 문제.
  MainViewModel 데이터 읽기 실패 후 화면 고정 문제. "990원" 하드코딩. 날짜 표기를 앱 언어 순서로. 매초 전체 재구성 → 집중 중에만.
  회전 시 다이얼로그 유실, 제한 사용 스위치 TalkBack 라벨, 취소 예외 처리 통일, 정렬 이름 복원 안전화.
- 결제·광고·계정: 구독자에게 시작 시 배너 잠깐 노출(마지막 구독 상태 저장). ITEM_ALREADY_OWNED 무시. 베이스 플랜 오퍼 선택.
  acknowledge 실패 로그. AdMob 앱 ID·배너 ID 둘 중 하나만 설정 시 빌드 실패. 광고 요청을 LaunchedEffect로. 로그아웃 시 자격증명 상태 정리.

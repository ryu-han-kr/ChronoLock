# 히스토리 월간 백필 인계 (Claude Code)

프로젝트 D:/Coding/ChronoLock. 사용자 요청: "월간 백필 진행해".

## 배경
- 기기는 사용 이벤트를 약 1주만 보관 → 설치 직후 "한 달" 보기가 사실상 "일주일". 이벤트 이전 기간을 OS 사용 통계 버킷으로 추정해 채움.

## 완료 (브랜치 feat/history-backfill → PR 병합)
- domain/HistoryBackfill.kt `estimateGapUsage`: 일→주→월 버킷 순(가장 세밀한 것 우선, 중복 집계 없음). 버킷 시간에서 이미 기록된 날의
  사용량을 빼고 나머지를 버킷 내 미기록 일수로 균등 배분, 공백 구간(첫 기록일 이전·30일 창 안·초기화 이후)에 속한 몫만 반환. 단위 테스트 6건.
- DB v4: `history_estimate`(packageName, date, appName, usageMillis) + MIGRATION_3_4, 스키마 4.json. 전체 삭제 시 추정도 삭제.
- HistoryRepository.collect(): 이벤트 반영 후 queryUsageStats(INTERVAL_DAILY/WEEKLY/MONTHLY)로 importEstimates.
  OS가 버킷을 지워 다시 계산 못 하는 날은 기존 추정 유지, 실제 기록이 생긴 날·30일 밖은 삭제, 홈 앱 제외.
- UI(HistoryScreen): 기간 합계·앱별 합계에 추정 포함, 안내 "X 이전은 기기 사용 통계로 추정한 시간… 실행 횟수 미포함",
  일별 기록에 "추정 N분", 앱 카드에 "추정 N 포함". 마스코트 평균은 기록+추정 일수 기준. 5개 언어 문자열.

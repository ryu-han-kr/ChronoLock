## 이번 작업에서 완료한 내용

- compileSdk·targetSdk 35 → 36(Play 요건: 2026-08-31부터 API 36). `gradle.properties`에 `android.suppressUnsupportedCompileSdk=36`을 추가했습니다(AGP 8.6.1).
  SDK Platform 36(r02, sha1 확인)을 사용자 SDK 폴더에 설치했습니다. CI도 `platforms;android-36`으로 바꿨습니다.
- Release 서명: `local.properties`의 `chronolock.releaseStoreFile/StorePassword/KeyAlias/KeyPassword`를 읽습니다.
  업로드 키는 `%USERPROFILE%\.chronolock\chronolock-upload.jks`(alias upload, RSA 4096, 10000일)로 생성했습니다. 사용자 백업이 필요합니다.
- AdMob 앱 ID가 없으면 `src/releaseNoAds/AndroidManifest.xml`이 AD_ID·ADSERVICES 권한을 제거합니다.
- `docs/PLAY_CONSOLE_GUIDE.md`: 할 일 순서, 내부 테스트 업로드, 앱 콘텐츠·접근성 신고 답변, 스토어 등록정보, 외부 키 발급 절차.

## 규칙·환경
- git은 `git -c safe.directory=D:/Coding/ChronoLock ...`. 긴 편집은 scratchpad 파이썬 + `python -I`. `rm -rf`는 권한 거부.
- 태블릿 SM-X810(Android 16) 무선 디버깅 `192.168.0.147:<포트>`(`adb mdns services`). 테스트는 `-PdeviceVerification=true`(앱 id `.verification`,
  테스트 광고 꺼짐). 긴 연결 테스트 전 화면 꺼짐 방지(`screen_off_timeout` 임시 변경 후 복구). opt-in 테스트 skip이 failure로 집계됨 → results.py로 판정.
- `uiautomator dump`는 실행 중 다른 접근성 서비스를 일시 중지시킴 → 차단 확인을 dump로 하면 오판. 시연 스크립트는 화면 픽셀로 확인.

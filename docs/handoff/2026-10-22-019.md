# 릴리스 0.6.2 실행 검증·감지 상태 표시 보강 인계 (Claude Code)

프로젝트 D:/Coding/ChronoLock. 사용자 요청: "0.6.2 업로드 완료, 다음 작업 진행".

## 완료
- 0.6.2 릴리스 APK(assembleRelease, 업로드 키 서명)를 에뮬레이터에 설치해 검증: 버전 0.6.2/vc10, 크래시 없음, 광고 미표시(키 없음),
  권한 부여 후 "앱 제한 감지 중", Chrome 하루 실행 1회 규칙 → 두 번째 실행에서 차단 화면 표시(실제 차단 동작 확인).
- MonitorHealth를 서비스 인스턴스 소유 기반으로 변경: 재시작 시 이전 인스턴스의 onDestroy가 늦게 와도 새 연결을 끊지 않음,
  오래된 인스턴스 오류 무시. onInterrupt(피드백 중단 신호)는 더 이상 연결 끊김으로 처리하지 않음. MonitorHealthTest 4건.
  서비스 연결·감지 시작 시 Log.i 추가.
- 조사 메모: uiautomator dump는 접근성 서비스를 잠시 해제·재연결하므로, dump 직후 화면에 "서비스 연결을 확인" 이 보일 수 있음.
  상태 확인은 스크린샷으로 한다(측정 방법 문제였고 실제 앱 버그는 아님).
- 에뮬레이터는 debug 빌드로 되돌림(서명 충돌 방지).

## 검증
- 단위 테스트(MonitorHealthTest 포함) 통과, lint 오류 0, assembleDebug·assembleRelease 성공. 위 릴리스 시나리오 수동 확인.
- 미검증: 실기기, 실결제·실광고.

# 테스터 초대 메일 미수신 확인 인계 (Claude Code)

- 프로젝트 D:/Coding/ChronoLock. 사용자 질문: "테스터 메일로 안오는데".
- 결론: Play 테스트는 초대 메일을 자동 발송하지 않음. 참여 링크를 직접 공유해야 함.

## 확인한 Play Console 상태 (2026-10-21, 읽기만)
- 게시 개요: "최근 게시일 2026년 10월 21일" → 검토 전송한 변경사항 승인·게시됨.
- 비공개 테스트 - 테스터들: 활성, 최신 출시 2 (0.2.0), 국가 1개, 이메일 목록 "비공개 테스터"(10명) 선택됨.
  참여 링크: https://play.google.com/apps/testing/com.chronolock.app
- 내부 테스트: 활성이지만 "임시 버전: 3 (0.3.0)" → 사용자가 올린 0.3.0이 아직 임시(출시 안 됨). 목록 "테스터"(1명)만 선택.
  참여 링크: https://play.google.com/apps/internaltest/4701365005747320545

## 사용자 할 일
1. 테스터 10명에게 비공개 테스트 링크 공유(목록에 등록된 Gmail로 로그인해야 함).
2. 프로덕션 신청 요건 12명 이상 → 비공개 테스터 목록에 2명 이상 추가.
3. 내부 테스트 0.3.0 임시 출시 → 출시 검토 → 출시(또는 0.5.0으로 교체). 비공개 트랙도 0.5.0으로 올리려면 새 버전 + 검토 전송.

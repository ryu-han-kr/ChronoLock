## 이번 작업: 카카오톡·네이버 앱 내 브라우저 사이트 차단
- 기기 조사 결과
  - 네이버 앱(`com.nhn.android.search`) 인앱 브라우저: 주소 표시 없음. 웹뷰(때로 `com.naver.xwhale.WebView` 안의 `android.webkit.WebView`)가 페이지 제목과 링크 `AccessibilityNodeInfo.targetUrl`만 노출. 웹뷰 트리는 접근성 서비스가 켜진 뒤 조금 지나야 생김.
  - 카카오톡: 인앱 브라우저 주소창 `com.kakao.talk:id/webview_navi_address_bar`에 `m.youtube.com`처럼 호스트가 표시됨(사용자가 카톡 링크를 열어 확인). `kakaotalk://inappbrowser?url=` 딥링크는 빈 페이지만 열림.
- 구현 (`domain/.../SiteBlock.kt`, `ChronoAccessibilityService.kt`)
  - `Browsers.urlBarIds`에 카카오톡 주소창 추가, `Browsers.inApp`·`watches`·`pageSite`·`pageHost`·`titleNames`.
  - 주소창에서 주소를 읽으면 그대로 사용. 못 읽는 인앱 앱은 웹뷰를 최대 600노드 BFS: 링크 3개 이상·과반이 가리키는 호스트 → 아니면 제목이 서비스 이름("YouTube", "… - YouTube")이면 차단. 웹뷰 없으면 차단 해제. 인앱 앱은 1초 간격 확인.
  - 지원 브라우저 문구 5개 언어에 "카카오톡·네이버 앱 내 브라우저" 추가.
  - 기기 테스트 `SiteBlockingDeviceTest#blockedSite_inNaverInAppBrowser_showsOverlay` 추가.
  - 버그 수정: 서비스 시작 시 이미 떠 있던 브라우저(또는 놓친 전환)는 확인 이벤트가 없어 차단 안 됨 → `render`에서 관찰 앱이 브라우저로 바뀌면 `requestSiteCheck` (PR #64).
- 검증(실제 실행): gradle 검증 종료 코드 0(수정 후 재실행). 태블릿 `SiteBlockingDeviceTest` 4/4(네이버 example.com 미차단, m.youtube.com 차단), 카카오톡 인앱 YouTube 위 차단 화면 표시 확인(임시 테스트, 수정 전 실패 → 수정 후 통과).

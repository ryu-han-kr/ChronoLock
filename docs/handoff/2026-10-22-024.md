## 완료 (브랜치 feat/groups-tile → PR #16, base = feat/strict-pause-schedules(PR #15) 위에 쌓음)
- domain/AppGroup.kt: `AppGroup`(이름, 멤버 2~20개, 공유 하루 시간·실행 횟수), `GroupDraft` 검증, `MonitorState.groupUsage`,
  `withGroups(rules, groups)` — 켜진 묶음의 멤버마다 group을 붙이고, 자기 규칙이 없거나 꺼진 멤버는 빈 규칙으로 추적·차단.
- Rules.kt: `AppRule.group`, `Reason.GROUP_USAGE/GROUP_OPENS`, RuleContext에 묶음 합계. UsageMonitor가 멤버 합계로 판정.
  쉬는 중(paused)인 앱은 묶음 한도도 적용 안 됨. 한 앱은 한 묶음에만(저장소에서 검사, `LocalRepository.GROUP_TAKEN`).
- Strictness.loosens(AppGroup?, AppGroup?): 삭제·끄기·한도 상향/제거·멤버 제외는 엄격 모드 대기. 멤버 추가·한도 하향은 즉시.
- DB v6: `app_groups`, `pending_groups` + MIGRATION_5_6, schemas/6.json(마이그레이션 SQL과 일치 확인). clearAll이 묶음도 삭제.
- LocalRepository: groups/pendingGroups, requestGroup/requestDeleteGroup/cancelPendingGroup, applyDue에서 대기 묶음 적용, ruleMap에 withGroups.
- UI: 오늘 탭 "앱 묶음" 섹션(GroupCard: 멤버·합계·남은 시간·대기 변경 취소), GroupEditor 시트(이름, 공유 시간·횟수, 앱 체크 목록·검색,
  다른 묶음 앱 비활성, 삭제). 차단 화면 문구 2종. 5개 언어 문자열 31개(타일 4개 포함).
- blocking/FocusTileService.kt: 빠른 설정 "집중" 타일. 누르면 앱에서 마지막으로 쓴 집중 길이(Preferences.focusMinutes, 기본 25분)로 시작,
  집중 중엔 종료(엄격 모드면 토스트로 거부). 규칙·권한이 없으면 앱을 연다. 잠금 화면에선 unlockAndRun. 부제: "HH:mm까지"/"N분 집중".

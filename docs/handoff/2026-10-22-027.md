- Chrome 화면 제어는 재시도 금지. 에뮬레이터는 adb(`$LOCALAPPDATA/Android/Sdk/platform-tools/adb.exe`, emulator-5554, 1080x1920)로
  input tap/swipe·screencap 사용. Git Bash에서는 `export MSYS_NO_PATHCONV=1` 필요. 디버그 앱 id = `com.chronolock.app`.
- uiautomator dump는 접근성 서비스를 잠깐 끊음(앱 버그 아님). 에뮬레이터 접근성은 현재 꺼져 있을 수 있음
  → `adb shell settings put secure enabled_accessibility_services com.chronolock.app/com.chronolock.blocking.ChronoAccessibilityService`.

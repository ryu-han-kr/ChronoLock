# 토큰 낭비 및 작업 실패 원인 진단 인계

- 프로젝트: `D:/Coding/ChronoLock`. 사용자 요청: 토큰 소모와 작업 미완료 원인 조사 및 해결책. 첨부: `.idea/.gitignore`.
- 조사와 프로젝트 실행 규칙 보완을 완료했다. 과거 앱 출시 작업은 이번 요청으로 재개하지 않았다.
- 확인: 루트 `.gitignore`의 `.idea/` 규칙이 첨부 파일과 workspace.xml을 이미 제외한다. 첨부 파일 변경은 불필요하다.
- 재현: 기본 `git status`는 sandbox 계정과 저장소 소유자 불일치로 실패한다.
- 검증: `git -c safe.directory=D:/Coding/ChronoLock status --short`는 성공한다. 사용자 전역 ignore 접근 경고는 남는다.
- 재현: `rg`가 PATH에 없다. PowerShell 검색으로 대체한다.
- 실패한 시도: `core.excludesFile=NUL`은 fatal 오류이므로 사용하지 않는다.
- 이전 최신 인계에도 동일 환경 오류가 있었으나 이번에 반복됐다. 실행 규칙에 반영되지 않은 알려진 오류가 낭비 원인이다.
- 현재 대화에 긴 공통 지침이 중복 포함돼 있다. 입력 증가 요인이지만 실제 과금·소비 비중은 측정하지 못했다.
- `AGENTS.md`에 Git 명령 단위 예외, 검색 대안, 재시도 조건, 좁은 검색 범위, 결과 확인 규칙을 추가했다.
- 기존 PowerShell 한글 경로 지침과 인계 의무는 보존했다. `.idea/.gitignore`, 앱 코드, 전역 설정은 변경하지 않았다.
- 검증: git diff --check 성공. git check-ignore -v로 `.idea/` 제외 확인. 문서 변경이라 앱 빌드·테스트는 미실행.
- 미커밋: 기존 AGENTS.md 변경 및 2026-10-20-001/002 인계에 이번 규칙과 이 파일이 추가됐다. 커밋하지 않았다.
- 미검증: 실제 토큰 사용량, IDE가 지침을 중복 삽입하는 정확한 경로, 과거 모든 실패의 원인.
- 필요 시 후속 우선순위: 해당 IDE 대화의 사용량/실행 기록으로 입력·출력·재시도 비중 확인.
- 운영 제안: 다음 작업은 새 대화에서 최신 인계 하나와 명확한 완료 조건으로 시작한다. 사용하지 않는 플러그인은 설정에서 정리하되 이번에는 변경하지 않았다.
- 장기적으로 IDE/호스트의 중복 지침을 제거해야 한다. AGENTS.md만으로 호스트가 제공하는 지침은 제거할 수 없다.

## 성능 (릴리스 빌드, 소프트웨어 렌더링 에뮬레이터 — 실기기보다 크게 느림)
- 콜드 스타트: 중앙값 1.48초, 최대 3.0초(디버그 빌드는 중앙값 2.3초).
- 프레임: 1,350프레임 중 지연 64%, 50번째 백분위 46ms. 캐릭터 숨쉬기·흔들림이 화면에 있는 동안 매 프레임 메시 그리기를 하므로
  CPU 렌더링 에뮬레이터에서는 수치가 나쁘게 나온다. **실기기(태블릿 SM-X810)에서 `dumpsys gfxinfo` 재측정 필요.**
  실기기에서도 지연이 크면: 화면 밖이거나 앱이 백그라운드일 때 애니메이션 정지, 메시 해상도(MESH=12) 축소, 깜빡임 프레임 미리 로드.
- 메모리(PSS): 릴리스 136MB(소프트웨어 GL이 네이티브 힙에 잡혀 부풀려짐).

## 감사에서 확인·수정한 버그 (PR #74)
1. 화면 잠금→해제 시 같은 앱을 새 실행으로 셈(재실행 대기 오발동, 실행 횟수 소모, 1회 시간 제한 우회).
2. 그룹에만 속한 앱이 집중 모드에서 빠짐.
3. 그룹 멤버 이름이 비면 규칙 맵 생성 실패로 감시 전체 중단.
4. 유니코드(한글) 도메인 미차단.

## 남은 위험 (미수정)
- PiP로 띄운 앱이 제한에 걸리면 홈으로 가도 차단 화면이 다시 뜸(기기 확인 필요).
- 기기 시계를 앞당기면 집중 모드가 일찍 끝남(벽시계 기준).
- 불확실: 구글 검색어가 주소창에 보일 때 오탐, 분할 화면에서 카카오톡이 Chrome의 사이트 차단을 해제, 통화 화면 위 차단 화면.
- Lint 경고: 영어 복수형 후보 4건("1 minutes" 가능), `UseKtx` 6, `CredentialManagerMisuse`(로그인 꺼져 있음), `LocalContextResourcesRead`, targetSdk 36.

# Play 스토어 등록정보 (ko-KR, 0.8.0)

Play Console → 스토어 등록정보 → 기본 스토어 등록정보에 붙여넣습니다. 광고·로그인·결제 버전을 출시하면 "권한과 개인정보" 문단을 고칩니다.

## 앱 이름 (30자 이내)

ChronoLock - 앱 사용 시간 제한

## 간단한 설명 (80자 이내)

내가 정한 기준으로 앱 사용 시간과 실행 횟수를 제한하고 집중 시간을 지키세요.

## 자세한 설명 (4000자 이내)

```text
무심코 연 앱에서 한 시간이 사라진 적이 있나요?
ChronoLock은 내가 직접 정한 기준에 따라 앱 사용을 제한해, 필요한 만큼만 쓰도록 돕습니다.

■ 앱별로 세밀한 제한
• 하루 사용 시간: 하루에 쓸 수 있는 총 시간을 정합니다.
• 1회 사용 시간: 한 번 열었을 때 쓸 수 있는 시간을 정합니다.
• 실행 횟수: 하루에 열 수 있는 횟수를 정합니다.
• 재실행 대기 시간: 닫은 뒤 다시 열기까지 기다릴 시간을 정합니다.
• 시간대 예약: 공부·업무·수면 시간처럼 정해진 시간에만 막습니다. 앱마다 여러 구간(매일·평일·주말)을 둘 수 있습니다.

■ 앱 묶음
SNS처럼 비슷한 앱 여러 개가 하루 시간과 실행 횟수를 함께 씁니다.

■ 엄격 모드와 잠시 쉬기
• 엄격 모드: 제한을 끄거나 느슨하게 바꾸면 정한 시간(10분~1시간)이 지나야 적용돼, 충동적으로 풀기 어렵습니다.
• 잠시 쉬기: 10분·30분·1시간·오늘만 제한을 멈추고, 끝나면 자동으로 다시 켜집니다.

■ 집중 모드
지금부터 정한 시간 동안 선택한 앱을 한 번에 막습니다. 빠른 설정 타일에서 바로 시작할 수 있습니다.

■ 사용 기록
최근 하루·일주일·한 달 동안 어떤 앱을 얼마나, 몇 번 열었는지 확인합니다.
제한 규칙이 없어도 기록을 볼 수 있습니다.
연속으로 한도를 지킨 날과 지난주 대비 사용량 변화도 보여 줍니다.

■ 웹사이트 차단
Chrome·삼성 인터넷 등 브라우저에서 youtube.com처럼 정한 사이트를 열면 차단 화면을 띄웁니다.
앱을 막아도 브라우저로 돌아가는 우회를 막을 수 있습니다.

■ 백업과 복원
제한 규칙, 앱 묶음, 설정을 파일로 내보내 재설치하거나 기기를 바꿀 때 그대로 복원합니다.

■ 권한과 개인정보
• 사용 정보 접근: 앱별 사용 시간과 실행 횟수를 확인하는 데 사용합니다.
• 접근성 서비스: 제한에 도달한 앱이 열렸을 때 차단 화면을 띄우기 위해 현재 실행 중인 앱의 이름을 확인합니다.
  웹사이트 차단을 쓰면 지원 브라우저 주소창의 도메인만 확인하며, 방문 기록은 저장하지 않습니다.
  그 밖의 화면 내용, 입력한 글자, 비밀번호는 읽지 않습니다.
• 모든 기록과 규칙은 이 기기에만 저장되며 서버로 전송하지 않습니다. 기록은 최대 30일간 보관됩니다.
• 백업 파일은 직접 고른 위치에만 저장되며 사용 기록은 포함하지 않습니다.
• 권한은 Android 설정에서 언제든 해제할 수 있습니다.

■ 지원 언어
한국어, English, 日本語, 简体中文, Español
```

# 숏폼 대본 (15~30초, 세로 1080×1920)

녹화 소스: `docs/store/chronolock-a11y-demo-0.8.0-ko.mp4`(태블릿 가로 → 세로로 크롭), 추가 장면은 휴대폰 화면 녹화.
공통: 첫 1.5초에 문제 제기 자막, 마지막 2초에 앱 이름·"Play 스토어 검색: ChronoLock". 음악은 YouTube 오디오 보관함 무료 음원.

## 1. "앱 막아도 크롬으로 보는 너" (18초)
| 초 | 화면 | 자막 |
|---|---|---|
| 0~2 | 유튜브 앱 차단 화면 | 유튜브 앱 막았다 ✅ |
| 2~5 | 크롬 열고 youtube.com 입력 | …근데 크롬으로 보면? 😏 |
| 5~9 | 차단 화면 등장(데모 85~92초) | 사이트도 막힘 |
| 9~15 | 앱의 웹사이트 차단 카드에 youtube.com 추가 | 주소만 넣으면 끝 (방문 기록 저장 안 함) |
| 15~18 | 로고 | ChronoLock |

## 2. "7일 참아야 비밀번호가 완성된다" (25초)
| 초 | 화면 | 자막 |
|---|---|---|
| 0~3 | 잠금 모드 → 목표 7일 → 조각 비밀번호 | 7일 동안 폰 참기 챌린지 |
| 3~12 | 날마다 "조각 받기" → `4 _ _ _ _ _ _` → `4 7 _ …` | 하루 지킬 때마다 비밀번호 한 자리 |
| 12~20 | 7자리 완성 → 잠금 풀기 | 7일 다 채워야 풀림 🔓 |
| 20~25 | 로고 | 나와의 약속, ChronoLock |

## 3. "내 1년 폰 사용, 달력으로 보면" (20초)
| 초 | 화면 | 자막 |
|---|---|---|
| 0~3 | 히스토리 → 1년 달력 | 내 1년 폰 사용량 |
| 3~10 | 진한 칸 눌러 시간 확인 | 이날 무슨 일이… |
| 10~16 | 날짜 눌러 앱별 사용 펼침 | 범인은 유튜브 |
| 16~20 | 실시간 알림(남은 시간) | 오늘은 여기까지만 |

촬영 순서: 휴대폰 연결 → 장면별 화면 녹화(`adb shell screenrecord`) → 편집(CapCut 등) → 쇼츠·릴스·틱톡 동시 업로드.

ChronoLock 개인정보처리방침

시행일: 2026년 10월 30일 (이전 개정 2026년 10월 26일, 2026년 10월 23일, 최초 2026년 10월 19일) · 개발자: beargris · 문의: hks.han666@gmail.com

ChronoLock(이하 "앱")은 사용자가 직접 정한 기준에 따라 앱 사용 시간과 실행 횟수를 제한하는 Android 앱입니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 요약

  • 앱은 개발자 서버로 개인정보를 전송하지 않으며, 제3자와 공유하지 않습니다.
  • 앱 사용 기록과 제한 규칙은 사용자의 기기 안에만 저장됩니다. 앱별 기록과 하루 합계는 최대 1년간 보관됩니다.
  • 현재 버전에는 광고, 로그인, 결제 기능이 없습니다.

2. 기기 안에서 처리하는 정보

책상 QR(켠 경우): 앱이 만든 무작위 비밀값, 집중을 끝낼 때 카메라로 찍은 QR의 글자(Google Play 서비스 코드 스캐너가 기기에서 읽음, 사진은 저장하지 않음)집중을 끝낼 때 이 기기의 QR인지 확인비밀값은 끌 때까지 기기 내, 찍은 글자는 확인에만 사용
사용자가 앱마다 적은 '미래의 나에게 한 줄'그 앱의 차단 화면에 표시사용자가 지울 때까지 기기 내, 백업 파일에는 포함하지 않음

백업 파일: 제한 규칙, 앱 그룹, 차단 사이트, 테마·언어·엄격 모드 설정. 사용 기록은 포함하지 않음재설치하거나 다른 기기에서 설정 복원기기의 다운로드/ChronoLock 폴더 또는 사용자가 고른 위치에 저장, 사용자가 직접 삭제

매주 자동 백업 파일은 기기의 다운로드/ChronoLock 폴더에 저장되며, 앱을 삭제해도 남습니다. 사용자가 폴더를 고르거나 "백업 파일 만들기"를 누르면 고른 위치(기기 저장소, 클라우드 드라이브 등)에 저장됩니다. 앱은 이 파일을 개발자나 제3자에게 전송하지 않으며, 클라우드 드라이브에 저장한 경우 해당 서비스의 정책이 적용됩니다.

3. 접근성 서비스(AccessibilityService) 사용

앱은 사용자가 정한 제한(하루 사용 시간, 1회 사용 시간, 실행 횟수, 재실행 대기 시간, 시간대 예약, 앱 그룹, 집중 모드)을 지키도록 돕기 위해 접근성 서비스를 사용합니다. 앱 전환 이벤트로 현재 앞에 있는 앱의 패키지 이름을 확인합니다. 웹사이트 차단에 사이트를 추가한 경우에만, 지원 브라우저(Chrome, 삼성 인터넷 등)가 화면에 있을 때 주소창에 표시된 주소에서 도메인(예: youtube.com)을 확인해 차단 목록과 비교합니다. 카카오톡·네이버 앱의 앱 내 브라우저처럼 주소가 화면에 보이지 않는 경우에는, 그 브라우저가 열려 있을 때에 한해 페이지 제목과 페이지 속 링크가 가리키는 도메인을 확인해 지금 열린 페이지가 차단 목록의 사이트인지 판단합니다.

  • 주소창(앱 내 브라우저는 페이지 제목과 링크 도메인) 외의 화면 내용, 본문, 입력한 글자, 비밀번호, 대화·메시지 내용은 읽지 않습니다. 주소창을 입력 중일 때는 확인하지 않습니다.
  • 확인한 주소·제목·링크와 방문 기록은 저장하지 않습니다.
  • 확인한 정보는 기기 밖으로 전송하지 않습니다.
  • 앱 안에서 사용 목적을 안내하고 동의한 경우에만 Android 설정으로 이동하며, 언제든 Android 설정에서 끌 수 있습니다.

4. 제3자 제공과 국외 이전

앱은 개인정보를 제3자에게 제공하거나 국외로 이전하지 않습니다. Android 백업도 사용하지 않아 기록이 Google 백업에 저장되지 않습니다.

5. 보관 기간과 삭제

  • 앱별 사용 기록과 1년 달력의 하루 합계는 1년이 지나면 오래된 날부터 차례로 자동 삭제됩니다.
  • 히스토리 탭의 "기록 삭제"에서 사용자가 정한 비밀번호를 입력하면 언제든 모든 기록을 지울 수 있습니다(비밀번호를 5번 틀리면 10분간 입력이 멈춥니다).
  • 설정의 "모든 규칙 초기화"로 제한 규칙·앱 그룹·웹사이트 차단을 지울 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다. 단, 다운로드/ChronoLock 폴더의 자동 백업 파일은 남으며 파일 앱에서 직접 지울 수 있습니다.

6. 사용자의 권리

사용 정보 접근 권한, 접근성 서비스, 알림 접근은 Android 설정에서 언제든 해제할 수 있습니다. 개발자는 사용자의 정보를 보유하지 않으므로 열람·정정·삭제는 위 방법으로 기기에서 직접 할 수 있습니다. 궁금한 점은 아래 연락처로 문의해 주세요.

7. 아동의 개인정보

앱은 만 13세 이상을 대상으로 하며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 방침 변경

광고, 로그인, 결제 등 정보 처리 방식이 달라지는 기능을 추가하면 시행 전에 이 페이지를 개정하고 변경 내용을 안내합니다.

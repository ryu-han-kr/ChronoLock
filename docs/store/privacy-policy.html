ChronoLock 개인정보처리방침

시행일: 2026년 10월 23일 (최초 2026년 10월 19일) · 개발자: beargris · 문의: hks.han666@gmail.com

ChronoLock(이하 "앱")은 사용자가 직접 정한 기준에 따라 앱 사용 시간과 실행 횟수를 제한하는 Android 앱입니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

1. 요약

  • 앱은 개발자 서버로 개인정보를 전송하지 않으며, 제3자와 공유하지 않습니다.
  • 앱 사용 기록과 제한 규칙은 사용자의 기기 안에만 저장되고 최대 30일간 보관됩니다.
  • 현재 버전에는 광고, 로그인, 결제 기능이 없습니다.

2. 기기 안에서 처리하는 정보

정보이용 목적보관
앱별 사용 시간·실행 횟수(사용 정보 접근 권한)제한 도달 여부 판단, 사용 기록(히스토리) 표시기기 내 최대 30일
현재 실행 중인 앱의 패키지 이름(접근성 서비스)제한에 도달한 앱이 열렸을 때 차단 화면 표시판정에만 사용
사용자가 만든 제한 규칙·앱 묶음·집중 모드·엄격 모드 설정제한 기능 제공사용자가 삭제할 때까지 기기 내
백업 파일(사용자가 직접 내보낸 경우): 제한 규칙, 앱 묶음, 테마·언어·엄격 모드 설정. 사용 기록은 포함하지 않음재설치하거나 다른 기기에서 설정 복원사용자가 고른 위치에 저장, 사용자가 직접 삭제

백업 파일은 사용자가 "백업"을 눌러 고른 위치(기기 저장소, 클라우드 드라이브 등)에만 저장됩니다. 앱은 이 파일을 개발자나 제3자에게 전송하지 않으며, 클라우드 드라이브에 저장한 경우 해당 서비스의 정책이 적용됩니다.

3. 접근성 서비스(AccessibilityService) 사용

앱은 사용자가 정한 제한(하루 사용 시간, 1회 사용 시간, 실행 횟수, 재실행 대기 시간, 시간대 예약, 앱 묶음, 집중 모드)을 지키도록 돕기 위해 접근성 서비스를 사용합니다. 앱 전환 이벤트로 현재 앞에 있는 앱의 패키지 이름만 확인합니다.

  • 화면 내용, 입력한 글자, 비밀번호, 메시지 등은 읽지 않습니다.
  • 확인한 정보는 기기 밖으로 전송하지 않습니다.
  • 앱 안에서 사용 목적을 안내하고 동의한 경우에만 Android 설정으로 이동하며, 언제든 Android 설정에서 끌 수 있습니다.

4. 제3자 제공과 국외 이전

앱은 개인정보를 제3자에게 제공하거나 국외로 이전하지 않습니다. Android 백업도 사용하지 않아 기록이 Google 백업에 저장되지 않습니다.

5. 보관 기간과 삭제

  • 사용 기록은 30일이 지나면 자동으로 삭제됩니다.
  • 앱 설정의 "모든 규칙과 사용 기록 삭제"로 언제든 모두 지울 수 있습니다.
  • 앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다.

6. 사용자의 권리

사용 정보 접근 권한과 접근성 서비스는 Android 설정에서 언제든 해제할 수 있습니다. 개발자는 사용자의 정보를 보유하지 않으므로 열람·정정·삭제는 위 방법으로 기기에서 직접 할 수 있습니다. 궁금한 점은 아래 연락처로 문의해 주세요.

7. 아동의 개인정보

앱은 만 13세 이상을 대상으로 하며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 방침 변경

광고, 로그인, 결제 등 정보 처리 방식이 달라지는 기능을 추가하면 시행 전에 이 페이지를 개정하고 변경 내용을 안내합니다.

# ChronoLock 캐릭터 Rive 애니메이션용 레이어 그림 요청서 (2026-10-26)

지금 캐릭터는 포즈마다 한 장짜리 그림이라 통째로 늘리고 기울이는 것밖에 못 합니다.
눈 깜빡임, 팔·귀·꼬리 움직임, 소품 움직임을 하려면 **부위별로 나뉜 그림(레이어)** 이 필요합니다.
이 문서는 일러스트레이터에게 그대로 전달할 수 있는 요청서입니다.

## 0. 진행 방식 (권장)

1. **햄스터(무료 캐릭터) 1종, 포즈 3개(기본·취침·성공)로 시범 제작** → 앱에 넣어 느낌·용량·성능 확인.
2. 괜찮으면 햄스터 나머지 7포즈 → 다른 4종으로 확대.
3. 알림·위젯·설정의 작은 미리보기는 Android 제약상 움직일 수 없어 **지금의 정지 이미지(webp)를 계속 사용**합니다. 정지 이미지는 완성된 Rive 장면에서 한 프레임씩 뽑아 다시 만들 수 있습니다.

## 1. 공통 규격

| 항목 | 요청 |
|---|---|
| 화풍 | 지금 캐릭터와 동일(`photo/chronolock` 원본 시트): 갈색 손그림 외곽선, 부드러운 털 질감, 볼 터치 |
| 형식 | 레이어가 살아 있는 **PSD 1개 + 레이어별 투명 PNG**. PNG는 모두 **같은 캔버스 크기·같은 위치**로 내보내기(잘라내지 말 것) — 겹쳐 놓으면 원래 그림이 되어야 함 |
| 캔버스 | 캐릭터당 1024×1024px, 투명 배경, 캐릭터는 아래쪽 정렬·발밑 여백 5% |
| 앱 표시 크기 | 최대 140dp(온보딩), 보통 56~96dp. 1024px이면 충분 |
| 가려지는 부분 | **겹치는 부위는 가려지는 쪽을 15~20% 더 그려 주세요.** (예: 팔이 몸통 위에 있으면 몸통은 팔 밑까지 이어서 그림, 머리 밑 목 부분도 채움) — 움직일 때 구멍이 생기지 않게 |
| 외곽선 | 각 부위가 자기 외곽선을 가짐. 이어지는 곳(어깨·목)은 외곽선이 끊겨도 됨 |
| 회전 기준점 | PSD에 점이나 메모로 표시: 목, 어깨 좌·우, 귀 뿌리, 꼬리 뿌리, 발목 |
| 이름 | 영어 소문자: `hamster/body.png`, `hamster/eye_l_open.png`, `prop/lock_body.png` … (아래 목록 이름 그대로) |

## 2. 캐릭터별 기본 부위 (5종 각각, 정면 앉은 자세 기준)

| 레이어 | 설명 |
|---|---|
| `body` | 몸통(배 털 포함), 팔·다리 없이 |
| `head` | 머리 윤곽·털, 얼굴 부위 없이(눈·입·볼 자리 비움) |
| `ear_l`, `ear_r` | 귀 좌·우 따로 (토끼·여우는 길게, 끝이 살짝 접히는 동작을 위해 뿌리부터) |
| `tail` | 꼬리 (너구리·여우·토끼·수달). 햄스터는 생략 |
| `foot_l`, `foot_r` | 앉은 발(발바닥 패드 보이게) |
| `arm_l_*`, `arm_r_*` | 팔 좌·우, 자세별: `down`(내림), `chest`(가슴 앞 모음), `hold`(물건 잡기), `up`(들어 올리기/만세), `wave`(손 흔들기) |
| `cheek_l`, `cheek_r` | 볼 터치(투명도 조절용) |
| `nose`, `whisker_l`, `whisker_r` | 코, 수염(수달·너구리·여우) |

## 3. 얼굴 표정 부위 (5종 각각)

눈은 **좌·우 따로**, 같은 위치에 겹치도록 그려 주세요.

| 레이어 | 쓰임 |
|---|---|
| `eye_*_open` | 기본 뜬 눈(하이라이트 포함) |
| `eye_*_half` | 반쯤 감은 눈(깜빡임 중간 프레임, 졸림) |
| `eye_*_closed` | 감은 눈(깜빡임, 취침) |
| `eye_*_happy` | 웃는 눈 ^^ (성공·해제·휴식) |
| `eye_*_teary` | 눈물 고인 눈 (사용 제한) |
| `eye_*_wide` | 놀란 큰 눈 (경고) |
| `eye_*_focus` | 집중한 눈(눈썹 살짝 내림) |
| `mouth_smile` · `mouth_open` · `mouth_small` · `mouth_wobble` · `mouth_o` · `mouth_sleep` | 미소 / 크게 웃음 / 작은 입 / 울먹 / 놀람 / 잠든 입 |
| `tear_l`, `tear_r` | 눈물 방울(떨어지는 동작용, 따로) |
| `sweat` | 땀방울 1개(복제해서 씀) |

## 4. 소품 (모든 캐릭터 공용 1벌, 크기만 맞춰 재사용)

| 포즈 | 레이어 |
|---|---|
| 잠금·해제 | `lock_body`(자물쇠 몸체), `lock_shackle_closed`, `lock_shackle_open`(고리 따로 — 열리는 동작) |
| 집중 | `desk`, `laptop_base`, `laptop_screen`(따로), `books`, `mug`, `steam`(김) |
| 타이머 | `clock_body`, `clock_hand`(바늘 따로, 중심점 표시), `clock_bell_l`, `clock_bell_r` |
| 사용 제한 | `phone`, `phone_block`(금지 표시 따로 — 깜빡임) |
| 휴식 | `cushion_back`, `cushion_front`(캐릭터가 파묻히도록 앞뒤로 나눔), `mug`, `steam` |
| 취침 | `nightcap`, `nightcap_pom`(방울 따로 — 흔들림), `blanket_back`, `blanket_front`, `pillow` |
| 경고 | `hourglass_frame`, `hourglass_sand_top`, `hourglass_sand_bottom`, `sand_stream`(떨어지는 모래) |
| 성공 | `trophy`, `medal`, `medal_ribbon`(따로 — 흔들림) |

캐릭터별로 소품 디자인이 다르면(예: 너구리 머리띠, 여우 안경, 토끼 호두) 그 캐릭터 폴더에 따로 넣어 주세요.

## 5. 효과 (공용, 하나씩 따로)

`heart`, `z_small`, `z_mid`, `z_big`, `exclaim`(느낌표), `ray`(강조선 1개), `sparkle`(반짝이), `confetti_1~4`(색종이 색·모양별), `drop`(물방울), `flower`(꽃잎), `moon`, `star`.

## 6. 만들 움직임 (Rive에서 제작, 그림 요청 범위 아님 — 확인용)

| 공통 | 숨쉬기(몸통·머리 미세 상하), 3~6초마다 무작위 눈 깜빡임, 가끔 귀 쫑긋, 꼬리 살랑 |
|---|---|
| 기본 | 가슴 앞 손 모으고 몸 살짝 흔들기, 하트 떠오름 |
| 잠금 | 자물쇠 꼭 껴안기(팔 조임) |
| 해제 | 고리 '딸깍' 열림 → 손 흔들기, 빛줄기 |
| 집중 | 타자 치는 손, 가끔 화면 보며 고개 끄덕, 머그 김 |
| 타이머 | 바늘 째깍, 몇 초마다 종 흔들림 |
| 사용 제한 | 눈물 맺힘·떨어짐, 금지 표시 깜빡임 |
| 휴식 | 머그 홀짝, 쿠션에 파묻혀 숨쉬기 |
| 취침 | 느린 숨, 모자 방울 흔들림, z가 차례로 떠오름 |
| 경고 | 모래 흐름, 땀방울, 느낌표 톡 튀어나옴 |
| 성공 | 트로피 들어 올림, 메달 리본 흔들림, 색종이 떨어짐 |
| 전환 | 포즈 사이 0.3초 자연스러운 전환. 앱에서 포즈 번호(0~9)를 입력으로 바꿈. "움직이는 효과 줄이기"면 정지 |

## 7. 개발 쪽 메모

- Android: `app.rive:rive-android` 런타임으로 `.riv` 1개(캐릭터당 또는 전체) 재생. 래스터 레이어는 메시 변형으로 털 질감을 유지한 채 휘게 할 수 있음.
- 용량: PNG 레이어가 많으면 `.riv`가 커짐 → 레이어는 WebP 변환·해상도 조정으로 캐릭터당 1MB 안쪽을 목표로 시범 제작 때 측정.
- 차단 화면(접근성 오버레이)은 View 기반이라 Rive View로 교체 가능. 알림·위젯·설정 미리보기는 정지 이미지 유지.
- 납품 확인 방법: PNG 전부를 순서대로 겹쳤을 때 원래 포즈와 같아야 하고, 각 팔·눈을 지워도 밑에 구멍이 없어야 합니다.

## 8. 분량 요약 (전달용)

- 캐릭터 5종 × (기본 부위 약 20개 + 표정 약 20개) ≈ 200레이어
- 공용 소품 약 30개 + 효과 약 20개 + 캐릭터별 전용 소품
- 시범(햄스터, 3포즈에 필요한 것만)은 약 40레이어

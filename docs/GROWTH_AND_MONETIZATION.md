# ChronoLock 유료화·홍보 계획 (2026-10-23 초안)

## 1. 결제: 토스페이먼츠를 앱에서 쓸 수 있나

- **Google Play 결제 정책**: Play로 배포한 앱 안에서 디지털 기능(프로 기능 잠금 해제, 광고 제거, 구독)을 팔면
  원칙적으로 **Google Play 결제(Billing)** 를 써야 한다. 토스페이먼츠 같은 외부 PG로 앱 안에서 결제받으면 심사 거절·앱 삭제 위험.
- **한국 예외 — 대체 결제(사용자 선택 결제)**: 한국 사용자에게는 Play 결제와 함께 **개발자가 고른 결제 수단을 나란히** 보여 줄 수 있다.
  Play Console에서 프로그램 신청·승인이 필요하고, 수수료가 약 4%p 낮아질 뿐 Google 수수료는 여전히 낸다(정확한 요율·조건은 신청 화면에서 확인).
  토스페이먼츠를 이 용도로 쓰려면 Google 요구사항(결제 화면 구성, 거래 보고 API)을 맞춰야 해 작업량이 크다.
- **웹 결제 → 앱 해제**: 웹사이트에서 팔고 앱은 로그인으로 권한만 확인하는 방식은, 앱 안에서 웹 결제로 **유도하지 않는다면** 가능하다.
  다만 로그인 서버(Supabase)를 다시 켜야 하고, 개인정보처리방침·데이터 보안 신고가 "수집 있음"으로 바뀐다.
- **권장**: 앱은 **Play 결제**(이미 `billing 9.1.0`과 광고 제거 구독 코드가 있음)로 시작하고, 토스페이먼츠는 웹사이트 상품에만 쓴다.
  대체 결제는 매출이 생긴 뒤 수수료 절감이 작업량보다 클 때 검토.
- 준비물: 통신판매업 신고(진행 중) → Play Console **결제 프로필(판매자)** 에 사업자 정보·정산 계좌 → 인앱 상품 등록.

## 2. 무료/유료 구분 제안

| 기능 | 무료 | 프로 |
|---|---|---|
| 앱 제한(하루·1회·횟수·대기·예약), 집중, 엄격 모드 | ✔ | ✔ |
| 앱 그룹 | 1개 | 무제한 |
| 웹사이트 차단 | 3개 | 50개 |
| 잠금 모드 | 기간 잠금 | 기간 + 목표 잠금·조각 비밀번호 |
| 기록 | 1개월 | 3개월 + 1년 달력 |
| 테마 | 기본 5개 | 전체 카탈로그 + 나만의 테마 |
| 광고 | 배너(설정 시) | 없음 |

- 가격 형태: **평생 이용권(인앱 상품, 예 9,900원)** + 선택형 월 구독(예 1,900원). 앱 성격상 일회성 구매 선호가 많음.
- 이미 쓰던 기능을 갑자기 막으면 리뷰가 나빠진다 → 기존 비공개 테스터는 프로 무료 제공(코드나 테스터 목록 기준).
- **구현 완료(꺼진 상태)**: 인앱 상품 `chronolock_pro_lifetime`(일회성) 구매·확인·acknowledge, 무료 한도(그룹 1·사이트 3·목표 잠금/테마/3개월 기록 제한),
  설정의 "ChronoLock 프로" 카드. 빌드 설정 `PRO_GATING`이 false라 지금은 모두에게 전부 열려 있다.
- **켜는 방법**: ① Play Console → 수익 창출 → 인앱 상품에 ID `chronolock_pro_lifetime` 등록·가격 설정·활성화
  ② 라이선스 테스터(설정 → 라이선스 테스트)에 본인 계정 추가 ③ `android/local.properties`에 `chronolock.proGating=true` 후 번들 빌드
  ④ 내부 테스트에서 구매·복원 확인 → 비공개/프로덕션. 기존 테스터 보상은 프로모션 코드(Play Console)로 지급.

## 3. 홍보 (무료 방법 적용안)

### ASO
- 검색어 후보: 앱 사용시간 제한, 스크린타임, 디지털 디톡스, 스마트폰 중독, 유튜브 차단, 인스타 차단, 앱 잠금, 공부 집중, 사이트 차단.
- 제목 제안(30자): `ChronoLock - 앱 시간 제한·사이트 차단` / 간단한 설명(80자):
  `유튜브·인스타 앱과 사이트를 시간·횟수로 제한하고, 잠금 모드로 스스로 약속을 지키세요.`
- 스크린샷 순서: ① 차단 화면 ② 실시간 알림 ③ 잠금 모드(조각 비밀번호) ④ 웹사이트 차단 ⑤ 1년 달력 ⑥ 그룹 ⑦ 테마.
  각 장면은 계측 테스트의 스크린샷 함수로 5개 언어 버전을 자동 생성할 수 있다(기기 연결 시).
- 영어·일본어·중국어·스페인어 등록정보는 `docs/store/STORE_LISTING_intl.md`.

### 커뮤니티
- 대상: 수험생(오르비·수만휘), 공시생, 대학생 커뮤니티, 육아(아이 폰 관리는 아님을 명확히), 개발자 커뮤니티(제작기).
- 형식: "유튜브 앱을 지워도 크롬으로 보게 돼서 만든 앱" 같은 **제작 계기 + 실제 쓰는 법**. 같은 글 반복 게시 금지, 각 커뮤니티 홍보 규칙 확인.

### 숏폼 (15~30초, 녹화 자료 재사용)
1. "앱 막아도 크롬으로 보는 너" → 크롬에서 youtube.com 열자마자 차단 화면(`docs/store/chronolock-a11y-demo-0.8.0-ko.mp4` 85초 부분).
2. "7일 참아야 비밀번호가 완성된다" → 조각 비밀번호가 하루 한 자리씩 채워지는 화면.
3. "내 1년 폰 사용, 달력으로 보면" → 1년 달력 색 변화.

## 4. 기록 보관 설계 메모 (사용자 요청 반영)

- Android는 상세 사용 이벤트를 약 1주만 보관 → 앱이 6시간마다 가져와 **앱별 하루 기록 90일**, **하루 합계 1년**을 따로 저장.
  원본 이벤트는 10일만 둬서 용량·계산 시간을 작게 유지(90일 원본을 모두 두면 수 MB·느린 재계산).
- 3개월 넘게 앱을 한 번도 열지 않아도 백그라운드 작업이 돌지만, 기기 절전 정책에 따라 빠질 수 있다.
- 기록 삭제 비밀번호는 해시로만 저장되어 **잊으면 복구 불가**(앱 삭제만 가능). 5회 실패 시 10분 정지.
- 1년 달력은 하루 1행(최대 366행)이라 용량 걱정 없음. 색은 사용자 본인 기록의 분위수 기준이라 적게 쓰는 사람도 대비가 보인다.
